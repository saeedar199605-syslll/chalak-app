# راهنمای انتقال به Cloudflare Pages

برای راه‌اندازی این سیستم در Cloudflare Pages و همگام‌سازی داده‌ها برای همه پرسنل، مراحل زیر را طی کنید:

1. فایل `server.ts` قدیمی را کاملا از پروژه حذف کنید (زیرا کلادفلر نیازی به بک‌اند اکسپرس ندارد).
2. پوشه `functions` و فایل `package.json` که در این فایل فشرده قرار دارند را دقیقاً در مسیر اصلی پروژه (کنار پوشه src) جایگزین فایل‌های قبلی کنید.
3. در پنل کلادفلر (بخش Workers & Pages > KV) یک دیتابیس به نام `CHALAK_DB` بسازید.
4. در تنظیمات پروژه کلادفلر خود:
   - در بخش Settings > Functions > KV Namespace Bindings متغیر `CHALAK_DB` را به دیتابیسی که ساختید متصل کنید.
   - در بخش Settings > Environment variables متغیر `GEMINI_API_KEY` را ایجاد کرده و کلید هوش مصنوعی خود را در آن وارد کنید.
